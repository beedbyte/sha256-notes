# SHA-256: structure and reduced-round models

Project page: [Beedbyte](https://beedbyte.tech/research/sha-256)

## English

**Question and scope.** This project explores structure in the SHA-256 message schedule and reduced-round models of its compression function. Any result must identify the model, round count, assumptions, and exact claim; a reduced-round result does not automatically apply to full SHA-256.

**Status.** The project is active. No result, manuscript, code, dataset, or reproduction package has been published for it here yet. No practical weakness in SHA-256 is claimed.

## Deutsch

**Frage und Umfang.** Dieses Projekt untersucht Strukturen in der SHA-256-Nachrichtenexpansion und Modelle der Kompressionsfunktion mit reduzierter Rundenzahl. Ein Ergebnis muss Modell, Rundenzahl, Voraussetzungen und genaue Aussage nennen; ein Ergebnis für ein Modell mit weniger Runden gilt nicht automatisch für vollständiges SHA-256.

**Stand.** Das Projekt läuft. Hier wurden dazu noch kein Ergebnis, Manuskript, Code, Datensatz oder Reproduktionspaket veröffentlicht. Eine praktische Schwäche von SHA-256 wird nicht behauptet.

## 中文

**问题与范围。** 本项目探索 SHA-256 消息扩展中的结构，以及轮数较少的压缩函数模型。任何结果都应注明模型、轮数、假设和准确命题；减轮模型的结果不能自动推广到完整 SHA-256。

**当前状态。** 项目仍在进行。目前尚未在此发布相关结果、手稿、代码、数据集或复现材料包。本项目没有声称 SHA-256 存在可实际利用的弱点。
